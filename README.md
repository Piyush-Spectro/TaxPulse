## Executive Overview

Over **70% of Indian salaried professionals** delay tax planning until March, leading to last-minute panic investments, forfeiture of legitimate HRA & 80C exemptions, and unexpected tax liabilities.

**TaxPulse** transforms tax management from a stressful March scramble into an ongoing, automated financial health habit. It introduces an instant 10-second estimator, a gamified 0-100 Tax Efficiency Score, personalized recommendation cards, an Old vs. New Tax Regime comparator, and a multi-income tracker.

---

## Key Features & Functional Specs

### 1. 10-Second Quick Tax Estimator
- Instant client-side tax liability calculation using salary sliders, age categories, and metro/non-metro HRA caps.
- Instant feedback on gross tax payable and immediate saving potential.

### 2. Gamified Tax Efficiency Score (0-100)
- Dynamic radial score metric quantifying profile completeness and deduction saturation across Section 80C, 80D, HRA, and optimal regime selection.

### 3. Old vs. New Tax Regime Arbitrage Engine
- Real-time side-by-side math breakdown comparing Section 115BAC (New Regime with Rs 75k std deduction) vs Old Tax Slabs.

### 4. Progressive Data Collection Checklist
- Low-friction interactive modals for Rent (HRA Exemption), 80C Investments (ELSS/PPF/NPS), 80D Health Insurance, and Home Loan Interest.

### 5. Multi-Income Stream Tracker
- Unified tax aggregation combining Salary, Freelance/Gig work, House Property Rental income, and Capital Gains.

### 6. In-App AI Tax Assistant Simulator
- Conversational widget providing plain-English query resolution for complex tax jargon and statutory rules.

## Tech Stack & Local Setup

No external build tools or node packages required.

```bash
# Clone the repository
git clone https://github.com/Piyush-Spectro/TaxPulse.git
cd TaxPulse

# Launch local test server
python3 -m http.server 8080
```
Open `http://localhost:8080` in your web browser.
